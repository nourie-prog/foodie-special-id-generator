# Foodie Special ID Generator

## Deskripsi
Program ini merupakan Mini Project P1 yang dibuat menggunakan bahasa C untuk menghasilkan ID unik berdasarkan karakteristik yang diisi dari pengguna.

## Input Program
1. Nama pengguna
2. Makanan favorit
3. Angka favorit

## Cara Kerja
1. Program meminta tiga input dari pengguna.
2. Angka favorit dikalikan 2 kemudian ditambah 10.
3. Data nama, makanan favorit, dan hasil pengolahan
   angka digabungkan menggunakan sprintf().
4. Program menampilkan ID yang dihasilkan.

## Library
Program hanya menggunakan stdio.h.
